In the last lesson, you used element selectors, which style every element of one type. That is a good start, but real pages need more control: you might want one paragraph to look different from the rest, or the prices on a menu to stand out. In this lesson you will learn the selectors that make this possible, using the class and id attributes you learned about in the HTML unit.

The starter code contains a menu page for a campus café. Some of its elements already have classes and IDs. As before, complete each Try It section in the editor before moving on.


Element Selectors: A Recap

An element selector uses an element's name and selects every element of that type:

li {
    color: dimgray;
}

This styles every list item on the page. Element selectors are ideal for setting the general look of a page, such as the colour of all paragraphs or all headings. When you need to style only some elements of a type, you need a more specific selector.


Class Selectors

A class selector selects every element with a particular class. It is written as a full stop followed by the class name:

<p class="note">All cakes are baked on site.</p>
.note {
    color: darkgoldenrod;
}

The full stop is only used in the CSS. In the HTML, the class attribute contains just the name.

A class selector works on any element with that class, whatever type of element it is. A <p>, a <span> and an <li> with class="note" would all be selected by .note. This is what makes classes so useful: you decide which elements belong together, and style them as a group.

⚠️ Warning: Class names are case-sensitive. .Price does not select class="price". Following the convention from the HTML unit, always write class names in lowercase, with hyphens between words, such as .opening-times.

Try It

  1. Every price on the menu is in a <span> with a class of price. In the CSS tab, add a rule that makes .price elements darkgreen.
  2. Look at the menu in the preview. One price has not changed colour, because its <span> is missing the class. Find it in the HTML and add class="price".

Elements With Several Classes

As you saw in the HTML unit, an element can have several classes, separated by spaces. It is then selected by each of its classes:

<span class="tag vegan">Vegan</span>
<span class="tag gluten-free">Gluten free</span>
.tag {
    background-color: whitesmoke;
}

.vegan {
    color: forestgreen;
}

.gluten-free {
    color: chocolate;
}

Both tags get the shared .tag style, and each one also gets the colour of its own type. This pattern, a general class plus a more specific one, is very common: it avoids repeating the shared styles in every rule.

Try It

  1. The dietary labels on the menu each have the tag class, plus either vegan or gluten-free. Add the three rules from the example above.
  2. The tomato soup is suitable for vegans, but has no label yet. Add a <span> after its price with the classes tag and vegan, containing Vegan. Check that it picks up both styles.

Combining an Element and a Class

You can write an element name and a class together, with no space between them, to select only elements of that type that also have that class:

p.note {
    color: darkgoldenrod;
}

This selects paragraphs with the note class, but not a <span class="note">. You will not need this often, since a well-named class usually only appears on one type of element anyway, but you will see it in other people's code.

⚠️ Warning: The space matters. p.note (no space) and p .note (with a space) mean completely different things. You will learn what the space means in Lesson 8.

ID Selectors

An ID selector selects the one element with a particular id. It is written as a hash followed by the ID:

<p id="opening-times">Open 8am to 4pm, Monday to Friday.</p>
#opening-times {
    background-color: lightyellow;
}

Because an ID must be unique on the page, an ID selector can only ever select one element.

💡 Tip: Most developers avoid ID selectors for styling, and use classes instead. A class can be reused if you later need a second element to look the same, and ID selectors are so strong that they are hard to override, as you will see in Lesson 5. Keep IDs for their other jobs, such as fragment link targets and form labels.

Try It

  1. The paragraph with the opening times has an id of opening-times. Give it a background-color of lightyellow using an ID selector.

The Universal Selector

The universal selector, *, selects every element on the page:

* {
    font-family: sans-serif;
}

This example changes every element to a font without small decorative strokes (a sans-serif font). You will learn about fonts properly in Lesson 4.

The universal selector is mostly used for a small number of settings that should apply to absolutely everything, usually at the very top of a stylesheet. You will see a common example in Lesson 6.

⚠️ Warning: Use the universal selector sparingly. Because it selects every element directly, it can stop elements picking up styles from the elements around them, which you will learn about in Lesson 5. For fonts and text colour, styling the body is usually a better choice.

Try It

  1. At the top of your CSS, add the universal rule from the example above. Notice that every piece of text on the page changes font.

Grouping Selectors

When several selectors need the same styles, you can group them into one rule by separating them with commas:

h1, h2 {
    color: saddlebrown;
}

This is exactly the same as writing two separate rules, but shorter, and easier to update. You can group any selectors, including classes and IDs:

h1,
h2,
.note {
    color: saddlebrown;
}

Writing each selector on its own line, as above, keeps long groups readable.

⚠️ Warning: If any selector in a group is invalid, the browser ignores the whole rule, not just that one selector. A common cause is a stray comma at the end of the group, such as h1, h2, { }.

Try It

  1. Add a grouped rule that makes the <h1> and every <h2> saddlebrown.
  2. Add a comma after h2, so the selector reads h1, h2,. Notice that neither heading is brown any more. Then remove the comma.

Choosing a Selector

  • Element selectors set the general look of every element of a type.
  • Class selectors style chosen groups of elements, and should be the selector you use most.
  • ID selectors work, but are best avoided for styling.
  • The universal selector is for the few settings that must apply to everything.
  • Grouping avoids repeating the same styles in several rules.

Check Your Page

Your CSS should contain rules similar to these, in any order:

* {
    font-family: sans-serif;
}

h1, h2 {
    color: saddlebrown;
}

.price {
    color: darkgreen;
}

.tag {
    background-color: whitesmoke;
}

.vegan {
    color: forestgreen;
}

.gluten-free {
    color: chocolate;
}

#opening-times {
    background-color: lightyellow;
}

Also check that every price is green, and that the tomato soup has a vegan label.
