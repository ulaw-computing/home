What Is CSS?

CSS stands for Cascading Style Sheets.

  • Style means presentation: colours, fonts, spacing, sizes and layout.
  • Sheets refers to the files that hold the styles, called stylesheets.
  • Cascading describes how the browser decides what to do when several styles apply to the same element. You will learn exactly how this works in Lesson 5.

HTML and CSS have separate jobs:

  • HTML describes the content and its structure: this is a heading, this is a list.
  • CSS describes how that content is presented: headings are navy and centred, lists have no bullets.

Keeping these jobs apart is called separation of concerns. It means you can completely redesign a website by changing only its CSS, without touching any of the HTML. It also means one stylesheet can style every page of a site, so a change in one place updates the whole site.

ℹ️ Info: The browser already applies some styles to every page, even when you have written no CSS. This is the browser default stylesheet (sometimes called the user agent stylesheet), and it is why headings are bold and large, links are blue and underlined, and lists have bullets. Your CSS builds on top of these defaults, and can override any of them.

Writing a CSS Rule

CSS is made up of rules. Each rule says which elements to style, and how to style them:

h1 {
    color: navy;
}

This rule makes every <h1> on the page navy. It has three parts:

  • The selector, h1, chooses which elements the rule applies to.
  • The declaration block is everything between the curly braces { }.
  • Inside the block is a declaration, color: navy;, which is made of a property (color), a colon, a value (navy) and a semicolon.

The property is what you want to change, and the value is what you want to change it to.

⚠️ Warning: CSS uses American spelling, so the property is color, not colour. Writing colour does not cause an error message; the browser simply ignores the declaration, because it does not recognise the property. You will meet the same thing with center rather than centre.

Try It

  1. Click the CSS tab in the editor. This is where you will write your styles.
  2. Below the comment, add a rule that makes the <h1> navy, exactly as in the example above.
  3. Check the preview: the main heading should now be navy.

Several Declarations in One Rule

A rule can contain as many declarations as you need. Each one goes on its own line, and each one ends with a semicolon:

h1 {
    color: navy;
    background-color: lightyellow;
    text-align: center;
}

Here, background-color sets the colour behind the heading, and text-align centres its text. You will learn about these properties properly in later lessons.

💡 Tip: The browser ignores whitespace in CSS, just as it does in HTML, so the whole rule could be written on one line. Putting each declaration on its own line, indented with Tab, makes your CSS much easier to read and edit, and is the standard convention.

Try It

  1. Add background-color: lightyellow; and text-align: center; to your h1 rule.
  2. Now delete the semicolon at the end of the color line. Notice that the heading loses its colour and its background colour.
  3. Put the semicolon back.
⚠️ Warning: Without the semicolon, the browser reads navy and the whole next line as a single value, navy background-color: lightyellow. That is not a valid colour, so it ignores the combined declaration, and both styles are lost. CSS does not show you an error; styles just stop working. When a style is not appearing, check for missing semicolons, colons and braces first. The semicolon after the last declaration in a rule is optional, but always including it means you cannot forget it when you add another line later.

Element Selectors

The selector h1 is an element selector (also called a type selector). It uses an element's name, without the angle brackets, and selects every element of that type on the page. p selects every paragraph, li every list item, and so on.

p {
    color: dimgray;
}

In the next lesson, you will learn selectors that target specific elements, rather than all of one type.

Try It

  1. Add a rule that makes every paragraph dimgray.
  2. Add a rule that makes every <h2> darkslateblue.
  3. Add a rule that gives the <body> a background-color of ghostwhite. Notice that this colours the whole page, because the body contains everything on it.

Three Ways to Add CSS

There are three places you can write CSS. They all work, but they are not equally good.

1. External Stylesheets

An external stylesheet is a separate file, ending in .css, that contains only CSS. It is connected to the HTML page with a <link> element in the <head>:

<head>
    <meta charset="UTF-8">
    <title>Study Tips</title>
    <link rel="stylesheet" href="styles.css">
</head>
  • rel="stylesheet" states the relationship: the linked file is a stylesheet for this page.
  • href is the path to the CSS file. It works exactly like the paths you learned in the HTML unit, so a stylesheet in a css folder would be href="css/styles.css".

This is how almost all real websites add their CSS, because:

  • One stylesheet can be linked from every page of a site, so the whole site shares one design.
  • Changing the stylesheet changes every page at once.
  • The browser downloads the file once and reuses it on every page, so pages load faster.
  • HTML and CSS stay completely separate.
ℹ️ Info: In this platform, the CSS tab is your external stylesheet, and the starter HTML already contains a <link> to it. When you click Download, your work is saved as index.html and styles.css, so the link works when you open the files on your own computer. The preview applies your CSS tab automatically, but on a real website, a page without a <link> would not load the stylesheet at all.

Try It

  1. Switch to the HTML tab and find the <link> element in the <head>. Check that you can identify its rel and href attributes.

2. Internal Stylesheets

An internal stylesheet is CSS written inside a <style> element in the page's <head>:

<head>
    <title>Study Tips</title>
    <style>
        h2 {
            color: darkgreen;
        }
    </style>
</head>

The rules work exactly the same way, but they only apply to this one page. Internal stylesheets are occasionally useful for a single page that needs its own styles, or for quick experiments.

3. Inline Styles

An inline style is written directly on an element, using the style attribute. There is no selector and no braces, because it only ever applies to that one element:

<p style="color: crimson;">This paragraph is crimson.</p>
⚠️ Warning: Avoid inline styles. They mix presentation back into the HTML, cannot be reused, and have to be changed one element at a time. They also override almost any rule in a stylesheet, which makes them very hard to work around later. You will see why in Lesson 5. You will still come across them, especially in HTML emails and in code generated by other tools, so it is important to recognise them.

Try It

  1. In the HTML tab, add a <style> element inside the <head>, below the <link>. Inside it, write a rule that makes <h2> elements darkgreen. Check the preview: the internal rule has replaced the darkslateblue colour from your CSS tab. You will learn why in Lesson 5.
  2. On the first paragraph of the page, add style="color: crimson;". Notice that only that one paragraph changes.
  3. Now remove both the <style> element and the style attribute. From now on, all of your CSS goes in the CSS tab.

Comments

CSS comments start with /* and end with */. The browser ignores everything between them. The same syntax works for every kind of comment:

/* A comment on its own line */

/*
   A comment that spans
   several lines
*/

h1 {
    color: navy; /* A comment at the end of a line */
}

As in HTML, comments are useful for explaining your code, labelling sections of a long stylesheet, and temporarily switching rules off ("commenting them out").

⚠️ Warning: CSS has no single-line comment. You may have seen // used for comments in other languages, such as JavaScript, but in CSS it is not a comment at all. The browser treats it as part of the code, which makes the next rule or declaration invalid, so it silently stops working. Always use /* */.

Try It

  1. At the top of your CSS, add the comment /* Study Tips page styles */.
  2. Comment out your body rule by wrapping the whole rule in /* and */. Check that the page background turns white again, then remove the comment markers.
  3. Above your h2 rule, add the line // Section headings. Check the preview: the <h2> headings have lost their colour.
  4. Change the // comment into a proper /* */ comment, and check that the colour comes back.

Check Your Page

Your CSS tab should look similar to this:

/* Study Tips page styles */

body {
    background-color: ghostwhite;
}

h1 {
    color: navy;
    background-color: lightyellow;
    text-align: center;
}

/* Section headings */
h2 {
    color: darkslateblue;
}

p {
    color: dimgray;
}

Also check that your HTML has no <style> element and no style attributes.
