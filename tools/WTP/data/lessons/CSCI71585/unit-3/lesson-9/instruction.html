Tutorial

Until now, your pages have mostly been a single column, with every block stacked below the one before. Real websites need more: a header with a logo on one side and navigation on the other, a row of cards that share the space evenly, a gallery of photos in a neat grid. Modern CSS has two layout systems designed for exactly this: flexbox and grid.

This is a longer lesson, so it is split into two parts. If you do not finish it in class, stop at the end of Part 1 or Part 2 and pick up from there. The starter code contains a page for a photography studio, which you will lay out using both systems. As before, complete each Try It section in the editor before moving on.


Containers and Items

Flexbox and grid work in the same basic way. You turn an element into a layout container by setting its display property, and its direct children become the items that it arranges:

<div class="cards">          <!-- the container -->
    <article>...</article>   <!-- an item -->
    <article>...</article>   <!-- an item -->
</div>
.cards {
    display: flex;   /* or display: grid; */
}

Only the direct children become items. Elements nested deeper inside them are laid out normally, unless you make their parent a container too.

⚠️ Warning: The most common mistake with both systems is putting display: flex or display: grid on the items instead of on their parent. If nothing happens, check which element you have set it on.

Part 1: Flexbox

Flexbox (the flexible box layout) arranges items in one direction at a time: either in a row or in a column. It is ideal for components such as navigation bars, rows of buttons, and the contents of a card.


Starting a Flex Layout

As soon as an element has display: flex, its items line up side by side in a row, each one only as wide as its content. They also stretch to the same height as each other.

Try It

  1. The page header contains two items: the studio's name and the <nav>. Give the header a display of flex. The name and the navigation now sit side by side.
  2. The navigation links are in a list. The starter CSS has already removed the list's bullets, which you will learn about in Lesson 10. Give the nav ul a display of flex too, so the links sit in a row.

The Two Axes

Flexbox arranges items along two axes:

  • The main axis is the direction the items flow in. By default, this is a row, from left to right.
  • The cross axis runs at right angles to it. In a row, this is vertical.

The flex-direction property sets the main axis:

  • row: left to right. This is the default.
  • column: top to bottom.
  • row-reverse and column-reverse: the same, in the opposite direction.

Every flexbox alignment property works along one of these axes, so changing the direction also changes which way they work.


Spacing and Alignment

gap

The gap property sets the space between items. Unlike margins, it never adds space around the outside of the first and last items.

justify-content

justify-content controls how items are spread out along the main axis:

  • flex-start: items packed at the start. This is the default.
  • flex-end: items packed at the end.
  • center: items packed in the centre.
  • space-between: the first item at the start, the last at the end, and equal space between the rest.
  • space-around and space-evenly: equal space around or between every item, including at the ends.

align-items

align-items controls how items line up along the cross axis:

  • stretch: items stretch to fill the container. This is the default, and is why flex items all match in height.
  • flex-start, flex-end and center: items keep their natural size, and line up at the start, end or centre.
💡 Tip: To remember which is which: justify-content works along the main axis, in the direction the items flow, and align-items works across it. In a normal row, that means justify is horizontal and align is vertical.

Try It

  1. Give the header a justify-content of space-between. The studio's name moves to the left edge and the navigation to the right.
  2. The name and the links are not quite level with each other. Give the header an align-items of center to line them up vertically.
  3. Give the nav ul a gap of 20px.

Centring

Centring something both horizontally and vertically used to be one of the hardest things to do in CSS. With flexbox, it takes three declarations on the container:

.hero {
    display: flex;
    justify-content: center;   /* centre along the main axis */
    align-items: center;       /* centre along the cross axis */
    min-height: 300px;
}

The container needs to be taller than its content for vertical centring to have any visible effect, which is why this example sets a min-height.

Try It

  1. The .hero section contains a heading and a paragraph. Make it a flex container with a min-height of 300px, and centre its content in both directions. Notice that the heading and paragraph sit side by side, because the direction is a row.
  2. Add flex-direction: column; to stack them. The content stays centred, because justify-content and align-items have swapped directions along with the axes.

Flexible Sizes

The "flex" in flexbox comes from the way items can grow and shrink to fill the available space. This is controlled by properties on the items, usually through the flex shorthand:

.card {
    flex: 1;
}

flex: 1 tells each item to grow to fill an equal share of the space. If one item had flex: 2, it would take twice as much of the leftover space as the others.

ℹ️ Info: flex is a shorthand for three properties: flex-grow, how much an item can grow; flex-shrink, how much it can shrink; and flex-basis, its starting size before growing or shrinking. flex: 1 means grow 1, shrink 1, and start from zero.

Wrapping

By default, flex items all stay on one line, shrinking as much as they can to fit. flex-wrap: wrap lets them move onto a new line when there is not enough room, which is essential on small screens. Combined with a minimum width, it creates a layout that adapts to any screen size:

.cards {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}

.card {
    flex: 1;
    min-width: 200px;
}

Try It

  1. The .services section contains three .card elements. Make .services a flex container with a gap of 20px. The cards sit in a row, but have different widths, because each fits its own content.
  2. Give each .card a flex of 1. The cards now share the width equally, and they are all the same height.
  3. Add flex-wrap: wrap; to .services and min-width: 200px; to .card. Open the pop-out preview and drag the edge of its window to make it narrower: when there is not enough room, the cards wrap onto a new line.

Part 2: Grid

CSS grid arranges items in two directions at once: in rows and columns. You define the grid on the container, and the items fill its cells in order. It is ideal for galleries, card grids and whole-page layouts.


Defining Columns

The grid-template-columns property defines the columns. Each value is the width of one column:

.gallery {
    display: grid;
    grid-template-columns: 200px 200px 200px;   /* three columns, 200px each */
    gap: 10px;
}

The items fill the cells from left to right, starting a new row whenever a row is full. You do not need to say how many rows there are: the grid creates as many as the items need.

The fr Unit

Fixed column widths do not adapt to the screen. Instead, grid has its own unit, fr, which means a fraction of the available space:

grid-template-columns: 1fr 1fr 1fr;   /* three equal columns */
grid-template-columns: 2fr 1fr;       /* the first column twice as wide as the second */
grid-template-columns: 250px 1fr;     /* a fixed column, and one that fills the rest */

When columns repeat, the repeat() function saves typing: repeat(3, 1fr) is the same as 1fr 1fr 1fr.

grid-template-rows defines rows in exactly the same way, but you rarely need it, since rows usually grow to fit their content.

Try It

  1. The .gallery contains six photos. Make it a grid container with three equal columns, using repeat() and fr, and a gap of 10px.
  2. Change it to four columns, and notice that the last row is only half full. Then change it back to three.

Placing Items

The lines between columns and rows are numbered, starting from 1 at the left and top edges. A three-column grid has four column lines:

line 1    line 2    line 3    line 4
  │ column 1 │ column 2 │ column 3 │

Items can be placed by saying which lines they start and end at, or how many columns or rows they should span:

.featured {
    grid-column: 1 / 3;   /* from column line 1 to column line 3: two columns wide */
    grid-row: span 2;     /* two rows tall */
}

grid-column: span 2 would also make the item two columns wide, starting wherever it would normally be placed.

Try It

  1. The first photo in the gallery has the class featured. Make it span two columns and two rows, using grid-column: span 2; and grid-row: span 2;. Notice how the other photos flow around it to fill the gaps.

Named Areas

For larger layouts, you can give areas of the grid names, and draw the layout as text with grid-template-areas. Each string in quotes is one row, and each word is one cell:

.page {
    display: grid;
    grid-template-columns: 200px 1fr;
    grid-template-areas:
        "header  header"
        "sidebar content"
        "footer  footer";
    gap: 10px;
}

.page-header  { grid-area: header; }
.page-sidebar { grid-area: sidebar; }
.page-content { grid-area: content; }
.page-footer  { grid-area: footer; }

Repeating a name, as with header header, makes that area span several cells. Each item is then placed into an area with the grid-area property. Each named area must form a rectangle, and a full stop (.) can be used for an empty cell.

Try It

  1. The Practice Area at the bottom of the page contains a .page element with four children. Add the CSS from the example above. The four boxes form a classic page layout.
  2. Change the middle row of grid-template-areas to "content sidebar". The sidebar moves to the right without any change to the HTML.

A Responsive Grid Without Media Queries

One combination of grid features creates a grid that automatically fits as many columns as there is room for:

.gallery {
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
}

This means: create as many columns as will fit (auto-fit), each at least 200px wide and sharing any extra space equally (minmax(200px, 1fr)). On a wide screen there might be five columns, and on a phone just one.

Try It

  1. Replace the gallery's grid-template-columns with the example above. Drag the edge of the pop-out preview's window to make it narrower and wider, and watch the number of columns change.

Flexbox or Grid?

Both systems can build many of the same layouts, and real websites use both, often one inside the other. As a general guide:

  • Use flexbox for layouts in one direction, where the content decides the sizes: a navigation bar, a row of buttons, the contents of a card, or centring a single item.
  • Use grid for layouts in two directions, where you want to control the rows and columns: a photo gallery, a grid of cards, or the overall layout of a page.

On this page, you used flexbox for the header, navigation, hero and service cards, and grid for the gallery and page layout.

⚠️ Warning: Flexbox and grid can display items in a different order from the HTML, using properties such as flex-direction: row-reverse, order, or by placing items in grid areas. Screen readers and keyboard navigation still follow the order of the HTML, so if the visual order is very different, the page becomes confusing for those users. Make sure the HTML order makes sense on its own.
