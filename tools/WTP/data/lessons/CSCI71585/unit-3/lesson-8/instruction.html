Tutorial

The selectors you have used so far choose elements by what they are, using their type, class or ID. In this lesson you will learn three more powerful kinds of selector. Combinators select elements by their relationship to other elements, such as links inside the navigation. Pseudo-classes select elements by their state or position, such as a link the mouse is hovering over, or every other row of a list. Pseudo-elements style a part of an element, such as its first letter, or add decorative content to it.

These selectors let you style a page precisely without adding classes to every element. The starter code contains a page for a walking tour company. As before, complete each Try It section in the editor before moving on.


Combinators

A combinator joins two selectors to describe a relationship between elements. The element that is styled is always the one described by the last part of the selector. There are four combinators.

Descendant: a Space

A space between two selectors selects elements that are anywhere inside another element, at any depth. You have already used this, in .hero-text h1 and .card h3.

nav a {
    color: white;
}

This selects every <a> that is inside a <nav>, whether it is a direct child or nested inside a list. Links elsewhere on the page are not affected.

Child: >

The > combinator selects only direct children: elements exactly one level inside the other.

.tours > li {
    font-weight: bold;
}

This selects the list items directly inside .tours, but not the list items in a list nested inside them.

Adjacent Sibling: +

The + combinator selects an element that comes immediately after another element, with the same parent.

h2 + p {
    font-size: 1.15rem;
}

This selects only the first paragraph straight after each <h2>, which is a common way to style the opening paragraph of each section.

General Sibling: ~

The ~ combinator selects every sibling that comes after another element, not just the next one.

h2 ~ p {
    color: #444;
}

This selects every paragraph that comes after an <h2> with the same parent.

⚠️ Warning: Remember from Lesson 2 that spaces matter. nav a is a descendant selector, while nav.main, with no space, selects a <nav> that has the class main.
💡 Tip: Keep combinator chains short, ideally two or three parts. A long selector such as body main section article ul li a is fragile, since it breaks if the HTML structure changes even slightly, and its specificity makes it hard to override. A class is often the simpler solution.

Pseudo-Classes

A pseudo-class selects an element when it is in a particular state, or in a particular position among its siblings. It is written with a single colon, straight after a selector with no space, such as a:hover.

Link and Interaction States

  • :link: a link that has not been visited yet.
  • :visited: a link to a page the user has already visited.
  • :hover: an element the mouse pointer is over.
  • :focus: an element that has keyboard focus, such as a link the user has tabbed to, or a form field they are typing in.
  • :active: an element at the moment it is being clicked.

Because these rules all have the same specificity, their order matters: a later rule overrides an earlier one when an element is in both states. To make sure each state appears when it should, write them in this order:

a:link    { color: teal; }
a:visited { color: darkslateblue; }
a:hover   { color: darkorange; }
a:focus   { color: darkorange; }
a:active  { color: crimson; }
💡 Tip: A popular way to remember the order is LoVe Hate For All: link, visited, hover, focus, active.
ℹ️ Info: To protect users' privacy, browsers only let :visited change colours. Otherwise, a website could detect which other sites you have visited by measuring how its links are displayed.

Focus Styles

Many people navigate the web using only a keyboard, pressing Tab to move from one link or form field to the next. The browser shows which element has focus with an outline, usually a blue or black ring.

⚠️ Warning: Never remove focus outlines with outline: none unless you replace them with a style that is at least as visible. Without one, keyboard users cannot see where they are on the page, which makes the site unusable for them. Removing focus outlines is one of the most common accessibility failures on the web.

You can make focus clearer, and match your design, with the outline property. It works like border, but does not take up any space, so it never moves the content around:

a:focus {
    outline: 3px solid darkorange;
    outline-offset: 2px;
}
ℹ️ Info: There is also a :focus-visible pseudo-class, which only applies when the browser thinks a visible focus indicator is needed, such as when the user is navigating by keyboard rather than clicking with a mouse.

Structural Pseudo-Classes

These pseudo-classes select elements by their position among their siblings:

  • :first-child: an element that is the first child of its parent.
  • :last-child: an element that is the last child of its parent.
  • :nth-child(n): an element at a particular position, counting from 1.

:nth-child() accepts a number, a keyword or a formula:

  • li:nth-child(3): the third item.
  • li:nth-child(odd) and li:nth-child(even): every other item. This is the usual way to create striped rows.
  • li:nth-child(3n): every third item: the 3rd, 6th, 9th and so on.
⚠️ Warning: p:first-child does not mean "the first paragraph". It means "a paragraph that is the first child of its parent". If a heading comes first, no paragraph matches. To count only elements of one type, use :first-of-type, :last-of-type or :nth-of-type() instead.

The :not() pseudo-class selects elements that do not match a selector. A common use is adding a line between items, but not after the last one:

.reviews li:not(:last-child) {
    border-bottom: 1px solid #ddd;
}

Pseudo-Elements

A pseudo-element styles a specific part of an element, or adds content that is not in the HTML. It is written with two colons, such as p::first-line, to distinguish it from a pseudo-class.

First Letter and First Line

  • ::first-letter styles the first letter of a block of text, which is how magazines create large opening letters (called drop caps).
  • ::first-line styles the first line of a block of text, however long that line turns out to be on the user's screen.
.intro::first-letter {
    font-size: 2.5rem;
    color: teal;
}

::before and ::after

::before and ::after insert content as the first and last thing inside an element. The content is set with the content property:

.tip::before {
    content: "Tip: ";
    font-weight: bold;
}

The inserted content can be styled like any other element. These pseudo-elements are often used for decorative touches, such as icons, quotation marks and arrows.

⚠️ Warning: A ::before or ::after pseudo-element only appears if it has a content property, even if it is empty: content: "";. It does not work on elements that cannot contain anything, such as <img> and <input>.
⚠️ Warning: Do not use ::before and ::after for important content. Screen readers handle generated content inconsistently, and it cannot be selected or copied by the user. If the content matters, put it in the HTML.
ℹ️ Info: You will often see the box-sizing rule from Lesson 6 written as *, *::before, *::after { box-sizing: border-box; }. This is because the universal selector does not select pseudo-elements, so they need to be included separately.

Specificity of the New Selectors

The new selectors fit into the specificity rules from Lesson 5:

  • Pseudo-classes count as classes. a:hover is (0, 1, 1).
  • Pseudo-elements count as elements. p::first-line is (0, 0, 2).
  • Combinators add nothing; only the selectors either side of them count. nav a is (0, 0, 2), and so is nav > a.
  • :not() itself adds nothing, but the selector inside it counts. li:not(.featured) is (0, 1, 1).

This explains what happened to your navigation links. nav a looks more targeted than a:link, but its specificity is (0, 0, 2), while a:link is (0, 1, 1). Comparing from the left, neither has an ID, and a:link has one class-level selector to nav a's none, so a:link won. Your new selector, nav a:link, is (0, 1, 2), which beats both.
