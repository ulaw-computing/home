Tutorial

Colour is often the first thing people notice about a website, and it does more than make a page look attractive: it creates a mood, draws attention to important content, and groups related things together. Used carelessly, it can also make a page hard or impossible to read. In this lesson you will learn the different ways to write colours in CSS, how to make colours transparent, how to check that text is readable, and how to add background images.

The starter code contains a page for a coastal walking route. Its CSS tab already has a few rules for spacing, which you will learn about in Lesson 6; leave those as they are. As before, complete each Try It section in the editor before moving on.


Text and Background Colours

You have already used the two main colour properties:

  • color sets the colour of an element's text (and of text decorations such as underlines).
  • background-color sets the colour behind an element's content, filling the whole area of the element.

So far you have written colours as names, such as navy. CSS has several other ways to write a colour, and you will see all of them in real code.


Colour Formats

Named Colours

CSS has around 140 named colours, from the obvious, such as red and white, to the more unusual, such as papayawhip and rebeccapurple. Names are easy to read, but there are not many of them, so they rarely match the exact colours of a real design.

Hexadecimal

Hex colours are the most common format on the web. A hex colour starts with #, followed by six hexadecimal digits: two each for the amount of red, green and blue light in the colour.

For example, in #94248C, 94 is the amount of red, 24 the amount of green and 8C the amount of blue. Each pair runs from 00 (none of that colour) to FF (the maximum, 255 in denary). So:

  • #000000 has no light at all, so it is black.
  • #FFFFFF has full red, green and blue, so it is white.
  • #FF0000 is pure red, and #0000FF is pure blue.
  • When all three pairs are equal, such as #767676, the colour is a grey.

If each pair is a repeated digit, a hex colour can be shortened to three digits: #FF0000 can be written #F00, and #333333 can be written #333. Hex colours are not case-sensitive, so #ff0000 and #FF0000 are the same.

ℹ️ Info: Hexadecimal is the base 16 number system, which uses the digits 0 to 9 followed by the letters A to F. Two hexadecimal digits can represent any number from 0 to 255, exactly the range that one byte can store.

RGB

The rgb() function describes the same three amounts of red, green and blue light, but as denary numbers from 0 to 255:

color: rgb(148, 36, 140);   /* the same colour as #94248C */

HSL

The hsl() function describes a colour in a way that is much closer to how people think about colour:

  • Hue: the position on a colour wheel, in degrees from 0 to 360. 0 is red, 120 is green and 240 is blue.
  • Saturation: how intense the colour is, from 0% (grey) to 100% (full colour).
  • Lightness: from 0% (black), through 50% (the pure colour), to 100% (white).
background-color: hsl(200, 70%, 40%);   /* a strong blue */
background-color: hsl(200, 70%, 90%);   /* a pale version of the same blue */

HSL makes it easy to create matching colours for a design: keep the hue the same, and change only the lightness to get darker and lighter versions.

💡 Tip: You do not need to work out colour values by hand. Most design tools give hex values, and you can search for "colour picker" in a search engine to find one that shows the same colour in hex, RGB and HSL.

Try It

  1. Give the body a color of #333, a dark grey that is softer on the eye than pure black.
  2. Make the h1 and every h2 the colour hsl(200, 70%, 30%).
  3. Give the .info box a background-color of hsl(200, 70%, 92%): a pale version of the same hue.
  4. Give the .warning box a background-color of rgb(255, 236, 179), a pale amber.

Transparency

Colours can be made partly see-through by adding a fourth value, called alpha, which runs from 0 (completely transparent) to 1 (completely solid):

background-color: rgba(0, 0, 0, 0.5);         /* black, 50% see-through */
background-color: hsla(200, 70%, 30%, 0.8);   /* blue, 80% solid */
ℹ️ Info: Modern CSS also accepts a newer, shorter syntax, where the values are separated by spaces and the alpha comes after a slash: rgb(0 0 0 / 0.5). Hex colours can include alpha too, as an extra pair of digits: #00000080. All of these do the same thing, and you will see all of them in other people's code.

Alpha or Opacity?

There is also an opacity property, which takes a value from 0 to 1. The difference is important:

  • A colour with alpha makes only that one colour transparent, such as the background.
  • opacity makes the whole element transparent, including its text, its images and everything inside it.

Try It

  1. Give the .badge element a background-color of hsl(200, 70%, 30%), a color of white, and an opacity of 0.5. Notice that the text has faded as well as the background.
  2. Remove the opacity, and change the background colour to hsla(200, 70%, 30%, 0.5). Now only the background is transparent, and the text stays fully solid.

Colour Contrast

Contrast is the difference in brightness between text and the colour behind it. Low contrast, such as light grey text on a white background, is hard to read for everyone, and can be impossible to read for people with low vision or colour blindness, or for anyone using a phone in bright sunlight.

Contrast is measured as a ratio, from 1:1 (no difference at all) to 21:1 (black on white). The Web Content Accessibility Guidelines (WCAG), the international standard for accessible websites, require at least:

  • 4.5:1 for normal text.
  • 3:1 for large text: at least 24px, or about 19px if it is bold.

You can check any pair of colours with the WebAIM Contrast Checker: enter the text colour and the background colour, and it tells you the ratio and whether it passes.

⚠️ Warning: Never use colour as the only way to show information, such as marking a required form field only by making its label red. Around 1 in 12 men and 1 in 200 women have some form of colour blindness. Always add text, an icon or another visual cue as well.

Try It

  1. The .footer-note paragraph at the bottom of the page has a color of #BBB in the starter CSS. Check #BBBBBB on #FFFFFF in the WebAIM Contrast Checker. It fails.
  2. Find a darker grey that passes for normal text, and update the rule. #767676 is the lightest grey that passes on white.

Background Images

The background-image property places an image behind an element's content. The image's path goes inside url():

.hero {
    background-image: url('images/coast.jpg');
}

Use background images for decoration. If an image is part of the content, and needs alt text, use an <img> element in the HTML instead: background images have no alt text, so screen reader users never know they are there.

⚠️ Warning: A path in url() is relative to the stylesheet, not to the HTML page. In this platform, your CSS is applied directly to the page, so images/coast.jpg works. In a real project where the stylesheet is in a css folder, you would need to go up a level first: url('../images/coast.jpg').
💡 Tip: Always set a background-color as well as a background image. The colour shows while the image is loading, and if it fails to load, so any text on top of it stays readable.

Try It

  1. Give the .hero section a background-image of url('images/coast.jpg'), and a background-color of hsl(200, 70%, 30%).
  2. Look at the preview. You can probably only see the top-left corner of the photo, because the image is larger than the space available.

Repeating

By default, a background image repeats (tiles) to fill the whole element, like wallpaper. The background-repeat property controls this:

  • repeat: tiles in both directions. This is the default.
  • repeat-x: tiles horizontally only.
  • repeat-y: tiles vertically only.
  • no-repeat: shows the image once.

Repeating is useful for small patterns and textures that are designed to tile seamlessly. For photographs, you almost always want no-repeat.

Sizing and Positioning

The background-size property controls how big the image is. Two keywords cover most situations:

  • cover: scales the image so it covers the whole element, cropping any parts that do not fit. This is ideal for large photos.
  • contain: scales the image so the whole image fits inside the element, leaving gaps if the shapes do not match.

The background-position property controls where the image sits, using keywords such as center, top, bottom, left and right. Two keywords can be combined, such as top right. When an image is cropped by cover, the position decides which part stays visible.

ℹ️ Info: background-size and background-position can also take exact sizes and distances, such as 200px. You will learn about CSS units in the next lesson.

Try It

  1. Add background-size: contain; to the .hero rule. The whole photo now fits the height of the section, and repeats to fill the width.
  2. Add background-repeat: no-repeat;. The photo now appears only once, with the background colour showing beside it.
  3. Change background-size to cover, and add background-position: center;. The photo now fills the section, centred.
  4. Try background-position: bottom; to see a different part of the photo, then change it back to center.

The background Shorthand

The background property is a shorthand: it sets several background properties in one declaration. When it includes a size, the size comes straight after the position, separated by a slash:

.hero {
    background: hsl(200, 70%, 30%) url('images/coast.jpg') center / cover no-repeat;
}

This one line does the same job as the five separate declarations in your .hero rule.

⚠️ Warning: A shorthand resets every property it covers, including any you leave out. If you write background: lightyellow; after setting a background image, the image is removed, because the shorthand sets it back to none. Use the shorthand when you are setting a background from scratch, and the individual properties when you only want to change one part.

Text on Images

Text placed on top of a photo is often hard to read, because a photo has light and dark areas. A common solution is to put the text on a semi-transparent background, which lets the photo show through while keeping the contrast high.

Try It

  1. Replace the five background declarations in your .hero rule with the background shorthand from the example above. The preview should look exactly the same.
  2. Give the .hero-text box a background-color of rgba(0, 0, 0, 0.6), and a color of white.
  3. The h1 inside the hero is still the blue you set earlier, which is hard to read on the dark box. Add a rule for .hero-text h1 that sets its colour to white. You will learn exactly how this selector works in Lesson 8.

Check Your Page

Your hero rules should look like this:

.hero {
    background: hsl(200, 70%, 30%) url('images/coast.jpg') center / cover no-repeat;
}

.hero-text {
    background-color: rgba(0, 0, 0, 0.6);
    color: white;
}

.hero-text h1 {
    color: white;
}

Also check that:

  • The headings use your HSL blue, and the info box uses a pale version of it.
  • The badge's text is fully solid, with only its background transparent.
  • The footer note passes the contrast check.
