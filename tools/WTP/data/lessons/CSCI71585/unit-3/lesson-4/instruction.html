Tutorial

Most of the web is text, so typography, the choice and arrangement of type, has a huge effect on how a page looks and how easy it is to read. In this lesson you will learn how to choose fonts and load them from Google Fonts, how to size and space text, and the units CSS uses for sizes and distances of every kind.

CSS Units

Many CSS properties need a size or a distance: font sizes, widths, spacing and more. A size in CSS is a number followed by a unit, with no space between them, such as 16px or 1.5rem. The only exception is zero, which needs no unit, since zero of anything is the same.

Units fall into two groups.

Absolute Units

The most common absolute unit is the pixel, px. A CSS pixel is a fixed size, roughly one dot on a standard screen. Pixels are predictable, which makes them a good choice for small, fixed details such as border widths.

ℹ️ Info: On high-resolution screens, such as most phones, one CSS pixel is drawn using several physical pixels, so a CSS pixel looks roughly the same size on every screen. CSS also has print units such as cm, mm and pt, but these are only useful for stylesheets designed for printing.

Relative Units

A relative unit is measured against something else, so it adapts when that thing changes:

  • %: a percentage of the parent element. For example, width: 50% is half the width of the parent.
  • em: relative to the element's font size. When used for font-size itself, it is relative to the parent's font size, so 2em is twice the parent's text size.
  • rem (short for root em): relative to the font size of the root element, <html>. In most browsers, this is 16px by default, so 1rem is 16px and 1.5rem is 24px.
  • vw and vh: 1% of the width and height of the viewport, the visible area of the browser window. 100vh is the full height of the screen.

Why Use rem for Text?

Users can change their browser's default text size in its settings, and many people with low vision do. Sizes in rem are based on this setting, so they grow and shrink to respect the user's choice. Text sizes in px ignore it.

💡 Tip: A good default is to use rem for font sizes, px for small fixed details such as borders, and % or the layout tools in Lesson 9 for widths. Avoid setting the <html> element's font size in pixels, since this overrides the user's setting for the whole page.

The Problem With em

Because em font sizes are relative to the parent, they compound when elements are nested:

.small {
    font-size: 0.8em;
}
<div class="small">
    This text is 0.8 × 16px = 12.8px.
    <div class="small">
        This text is 0.8 × 12.8px = 10.24px.
    </div>
</div>

With rem, both would be 0.8 × 16px, however deeply they were nested.

Try It

  1. The Practice Area at the bottom of the starter page has three nested <div> elements with the class small. Give .small a font-size of 0.8em, and notice that the text shrinks at each level.
  2. Change the unit to 0.8rem. All three levels are now the same size.

Fonts

font-family and Font Stacks

The font-family property chooses the font. Its value is a font stack: a list of fonts, separated by commas, in order of preference.

body {
    font-family: "Open Sans", Arial, sans-serif;
}

The browser uses the first font in the list that is available. If the user does not have Open Sans, it tries Arial, and if that is missing too, it uses its default sans-serif font. Font names that contain spaces must be written in quotes.

The last item in a stack should always be a generic family, which every browser can provide:

  • serif: fonts with small strokes at the ends of letters, such as Times New Roman. Often used for a traditional or formal feel.
  • sans-serif: fonts without those strokes, such as Arial. Clean and modern, and the most common choice for body text on screen.
  • monospace: every character is the same width, such as Courier. Used for code.
  • system-ui: the default font of the user's operating system.
ℹ️ Info: Fonts that almost every computer already has installed, such as Arial, Georgia and Courier New, are often called web-safe fonts. Any other font has to be downloaded by the browser before it can be used.

Google Fonts

Google Fonts is a free library of fonts that any website can use. You choose a font, and Google Fonts gives you a <link> element to add to your HTML. This link loads a stylesheet that downloads the font files for you. You then use the font's name in your own CSS, as normal.

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Merriweather:wght@700&family=Open+Sans:ital,wght@0,400;0,700;1,400&display=swap">

This link loads two fonts: Merriweather in bold (weight 700), and Open Sans in regular, bold and italic.

💡 Tip: Put the Google Fonts link above the link to your own stylesheet. Only load the fonts, weights and styles you actually use: each one is an extra file the user has to download, which slows down the page. Two font families is usually plenty for a whole site.

  1. In the HTML tab, add the Google Fonts <link> from the example above to the <head>, above the link to styles.css.
  2. In the CSS tab, give the body a font-family of "Open Sans", Arial, sans-serif.
  3. Give the h1 and h2 elements a font-family of Merriweather, Georgia, serif.

Font Size, Weight and Style

  • font-size sets the size of the text, using any of the units above.
  • font-weight sets how thick the text is. It accepts normal and bold, or numbers from 100 (thin) to 900 (very heavy), where 400 is normal and 700 is bold.
  • font-style sets italic or normal text.
h1 {
    font-size: 2.5rem;
    font-weight: 700;
}

.caption {
    font-size: 0.875rem;
    font-style: italic;
}
⚠️ Warning: A web font can only display the weights and styles that have been loaded. If you set font-weight: 300 but only loaded weights 400 and 700, the browser uses the nearest one available. If the italic version has not been loaded, it fakes italics by slanting the regular letters, which usually looks poor.
ℹ️ Info: Remember that font-weight and font-style only change how text looks. If text is important or stressed, mark it up with <strong> or <em> in the HTML, as you learned in the HTML unit. CSS can then change how those elements look.

  2. Give the .standfirst paragraph, the introduction below the title, a font-size of 1.25rem.
  3. Give the .pull-quote a font-size of 1.5rem and a font-style of italic.

Styling Text

Line Height

line-height sets the distance between lines of text. Text with too little line height feels cramped and is hard to follow from one line to the next. For body text, a line height of around 1.5 is a good starting point.

body {
    line-height: 1.5;
}

Write line-height as a number with no unit. This means "1.5 times the font size", so it adjusts automatically for every element, including large headings and small captions. A value with a unit, such as 24px, would be the same for every element, however big or small its text.

Alignment

text-align sets the horizontal alignment of text within its element: left, right, center or justify.

⚠️ Warning: Avoid justify for body text on the web. To make every line the same length, the browser stretches the gaps between words, which creates uneven "rivers" of white space that make text harder to read, especially for people with dyslexia. Centred text is fine for short headings, but hard to read in long paragraphs, because each line starts in a different place.

Decoration, Case and Spacing

  • text-decoration adds or removes lines: underline, line-through, overline or none.
  • text-transform changes the case of the letters: uppercase, lowercase or capitalize. It only changes how text is displayed, not the text itself.
  • letter-spacing adds space between letters. Small amounts in em work best, such as 0.1em.
.label {
    text-transform: uppercase;
    letter-spacing: 0.1em;
}
⚠️ Warning: Be careful with text-decoration: none on links. The underline is how most people recognise a link, especially people who cannot distinguish colours. If you remove it, the link must still be clearly different from the text around it.
💡 Tip: If text should be in capitals only as a style, such as a label, type it normally in the HTML and use text-transform: uppercase. Some screen readers may read words typed in capitals letter by letter, as if they were abbreviations.

The font Shorthand

The font shorthand sets several font properties in one declaration. The values must go in this order, and the size and family are required:

/* font: style weight size/line-height family; */
.pull-quote {
    font: italic 400 1.5rem/1.4 Merriweather, Georgia, serif;
}

The line height is optional, and comes straight after the size, separated by a slash.

⚠️ Warning: Like the background shorthand, font resets every property it covers. Any value you leave out, such as the line height, goes back to its default. For this reason, many developers prefer to write the individual properties.

Viewport Units for Text?

It can be tempting to size headings in vw, so they grow and shrink with the screen.

Try It

  1. Temporarily change the h1 font size to 5vw, then open the fullscreen preview. The heading is much larger on the wider screen.
  2. Change it back to 2.5rem.
⚠️ Warning: Text sized only in vw does not grow properly when the user zooms in: zooming makes the viewport narrower in CSS pixels, so the vw size shrinks and cancels out the zoom. It also ignores the user's text size setting. This fails accessibility guidelines, which require text to be resizable. You will learn better ways to adjust text for different screens in Lesson 11.

Check Your Page

Your typography rules should be similar to these:

body {
    font-family: "Open Sans", Arial, sans-serif;
    line-height: 1.6;
}

h1,
h2 {
    font-family: Merriweather, Georgia, serif;
}

h1 {
    font-size: 2.5rem;
}

h2 {
    font-size: 1.5rem;
}

.byline {
    font-size: 0.875rem;
    text-transform: uppercase;
    letter-spacing: 0.1em;
}

Also check that the headings use Merriweather and the body text uses Open Sans, the pull quote is large, italic and centred, and the old product name is crossed out.
