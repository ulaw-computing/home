You will learn how the browser represents a page so that JavaScript can work with it, how to find any element on the page, and how to change its text, its classes, its styles and its attributes. This is what makes JavaScript so useful on the web.

The starter code contains a product page for a pair of headphones. As before, keep the console open, and complete each Try It section in the editor before moving on.


What Is the DOM?

When the browser loads an HTML page, it does not keep the HTML as text. It builds a model of the page in memory, called the Document Object Model, or DOM. In the DOM, every element is an object: a bundle of information and actions that JavaScript can read and change.

The DOM is arranged as a tree, following the nesting of the HTML. You met these family-tree terms in the HTML unit and in CSS selectors:

document
└── html
    ├── head
    │   └── title
    └── body
        ├── h1
        └── main
            ├── p
            └── ul
                ├── li
                └── li

The key thing to understand is that the preview shows the DOM, not your HTML. When JavaScript changes the DOM, the page on screen updates immediately, but the HTML in the editor stays exactly as you wrote it.

The whole page is available in JavaScript through a variable called document, which is the starting point for everything in this lesson.


Selecting Elements

Before you can change an element, you need to find it. The most useful tool for this is document.querySelector(), which takes a CSS selector, as a string, and returns the first element on the page that matches it:

document.querySelector("#product-name");     // the element with this ID
document.querySelector(".price");            // the first element with this class
document.querySelector("h1");                // the first h1
document.querySelector(".features li");      // the first li inside .features

Every selector you learned in the CSS unit works here, including combinators and pseudo-classes.

If nothing on the page matches, querySelector returns null, meaning "nothing". This is what happened in Lesson 1, when the script ran before the page had been built.

Storing Elements in Variables

If you need to use an element more than once, select it once and store it in a const. This keeps your code shorter, easier to read, and faster, since the browser does not have to search the page every time:

const productName = document.querySelector("#product-name");

console.log(productName);   // shows the element in the console
💡 Tip: When you log an element, the console shows it as HTML. Click the small arrow beside it to see the elements inside it.

Try It

  1. In the JS tab, select the element with the ID product-name, store it in a const called productName, and log it.
  2. Select the element with the class price, store it in a const called price, and log it.

Changing Text

The textContent property is the text inside an element. You can read it, to find out what the element says, or assign to it, to replace the text completely:

console.log(productName.textContent);       // reads the current text
productName.textContent = "Studio Headphones Pro";   // replaces it

Try It

  1. Log the current textContent of productName.
  2. Change it to Studio Headphones Pro, and check that the preview updates. Look at the HTML tab: the original name is still there, because JavaScript changed the DOM, not your HTML.
  3. The headphones are in a sale. Change the text of price to £79.99.

textContent and innerHTML

There is a second property, innerHTML, which reads and writes the HTML inside an element. The difference is in how the new value is treated:

  • textContent treats the value as plain text. Any tags in it are displayed as text, exactly as typed.
  • innerHTML treats the value as HTML. The browser reads any tags in it and creates real elements.
const note = document.querySelector(".delivery-note");

note.textContent = "Free delivery <strong>today</strong>";   // shows the tags as text
note.innerHTML = "Free delivery <strong>today</strong>";     // shows today in bold
⚠️ Warning: Never put anything a user has typed, or any data from outside your own code, into innerHTML. Because innerHTML turns text into real HTML, someone could type HTML that runs their own JavaScript on your page, for example to steal other users' information. This attack is called cross-site scripting (XSS), and it is one of the most common security problems on the web. You will learn more about it in the next unit. textContent is always safe, because it never creates elements, so use it unless you specifically need HTML.

Try It

  1. Select the .delivery-note paragraph, and set its textContent to the string from the example above. Notice the tags appear as text.
  2. Change textContent to innerHTML. Now today is bold.

Selecting Several Elements

querySelector only ever returns the first match. To get every matching element, use document.querySelectorAll():

const features = document.querySelectorAll(".features li");
console.log(features.length);   // the number of elements found

querySelectorAll returns a list of elements, called a NodeList. You cannot change the whole list at once, so to change each element, you go through the list one item at a time with forEach:

features.forEach((feature) => {
    feature.classList.add("highlight");
});

forEach takes a callback, like setTimeout in the last lesson, and calls it once for every item in the list. Each time, the current item is passed in as the parameter, here called feature. You will learn about lists, and forEach, properly in Lesson 7.

If nothing matches, querySelectorAll returns an empty list, with a length of 0.

Try It

  1. Select all of the .features li elements, and log how many were found.
  2. Use forEach to log the textContent of each one.

Changing Classes

The best way to change how an element looks is to add or remove a class, and let the CSS decide what the class looks like. This keeps the presentation in your CSS, where it belongs. Every element has a classList with four useful methods:

  • classList.add("name") adds a class.
  • classList.remove("name") removes a class.
  • classList.toggle("name") adds the class if the element does not have it, and removes it if it does.
  • classList.contains("name") returns true if the element has the class, and false if not.
price.classList.add("on-sale");

Notice there is no full stop before the class name. A full stop is only needed in a selector, such as in querySelector(".price"), to say "this is a class". classList already knows it is working with classes.

Try It

  1. The starter CSS has an .on-sale class, which makes text red and bold. Add it to price.
  2. Use your forEach loop to add the highlight class to every feature.
  3. The page has a paragraph with the class stock-warning, which is hidden by the CSS class hidden. Remove the hidden class, to show it.

Changing Styles Directly

Every element also has a style property, which sets inline styles on it:

productName.style.color = "darkslateblue";
productName.style.backgroundColor = "lightyellow";

CSS property names that contain a hyphen are written in camelCase in JavaScript, since a hyphen would mean subtraction: background-color becomes backgroundColor, and font-size becomes fontSize. The values are always strings, including units, such as "20px".

⚠️ Warning: Styles set with style are inline styles, which, as you learned in the CSS unit, beat almost every rule in your stylesheet and are hard to override. Prefer adding and removing classes. Use style only for values that genuinely have to be calculated by JavaScript, such as the position of something being dragged.

Changing Attributes

JavaScript can read and change any HTML attribute:

  • getAttribute("name") returns the attribute's value.
  • setAttribute("name", "value") sets it, adding the attribute if it is not there.
  • removeAttribute("name") removes it.

Many common attributes can also be used directly as properties, which is shorter:

const productImage = document.querySelector(".product-image");

productImage.src = "https://placehold.co/400x300?text=Black";
productImage.alt = "Studio Headphones Pro in black";
💡 Tip: Whenever you change an image's src, update its alt text too, so that it still describes the image that is now shown.

Try It

  1. Select the .product-image, and change its src and alt to show the black version, as in the example above.
  2. Select the .buy-link, and use setAttribute to change its href to #basket. Log getAttribute("href") to check it has changed.

Check Your Page

Your JavaScript should be similar to this:

const productName = document.querySelector("#product-name");
const price = document.querySelector(".price");
const note = document.querySelector(".delivery-note");
const features = document.querySelectorAll(".features li");
const productImage = document.querySelector(".product-image");
const buyLink = document.querySelector(".buy-link");

productName.textContent = "Studio Headphones Pro";
price.textContent = "£79.99";
price.classList.add("on-sale");
note.innerHTML = "Free delivery <strong>today</strong>";

features.forEach((feature) => {
    feature.classList.add("highlight");
});

document.querySelector(".stock-warning").classList.remove("hidden");

productImage.src = "https://placehold.co/400x300?text=Black";
productImage.alt = "Studio Headphones Pro in black";
buyLink.setAttribute("href", "#basket");

Also check that the price is red, every feature is highlighted, the stock warning is visible, and the black headphones image is shown.
