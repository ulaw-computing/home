Tutorial

Most real data comes in lists: the items in a basket, the posts in a feed, the results of a search. Storing each one in its own variable would quickly become impossible. In this lesson you will learn how JavaScript stores lists of values in arrays, and how to repeat code for every item in a list using loops and the array methods that make working with lists so much simpler.

The starter code contains a revision planner, with spaces for a list of topics and a set of practice test results. As before, keep the console open, and complete each Try It section in the editor before moving on.


Arrays

An array is an ordered list of values, stored in a single variable. It is written in square brackets, with the values, called elements or items, separated by commas:

const topics = ["HTML", "CSS", "JavaScript"];

An array can hold any type of value, including numbers, booleans and even other arrays, although most arrays hold items of one type.

Indexes

Each item has a numbered position, called its index. Indexes start at 0, not 1, so the first item is at index 0, the second at index 1, and so on. You get an item by writing its index in square brackets after the array's name:

console.log(topics[0]);   // "HTML"
console.log(topics[2]);   // "JavaScript"
console.log(topics[5]);   // undefined: there is no item at index 5

The length property is the number of items. Because indexes start at 0, the last item is always at index length - 1:

console.log(topics.length);                   // 3
console.log(topics[topics.length - 1]);       // "JavaScript"

You can also change an item by assigning to its index: topics[0] = "HTML5";.

ℹ️ Info: Notice that topics is declared with const, but its items can still be changed. const stops the variable being replaced with a completely different value, but the array it holds can still be changed. Arrays are almost always declared with const.

Changing Arrays

Arrays have built-in methods for adding and removing items:

  • push(item) adds an item to the end.
  • pop() removes the last item, and returns it.
  • unshift(item) adds an item to the start.
  • shift() removes the first item, and returns it.

Two more methods help you search an array:

  • includes(item) returns true if the array contains the item, and false if not.
  • indexOf(item) returns the index of the item, or -1 if it is not in the array.

And join(separator) joins every item into one string, with the separator between them, which is very useful for displaying an array:

topics.push("Accessibility");
console.log(topics.join(", "));   // "HTML, CSS, JavaScript, Accessibility"

Loops

A loop repeats a block of code. Loops are what make arrays so powerful: whether a list has three items or three thousand, one loop can do something with every one of them.

The for Loop

The classic for loop repeats a block a set number of times, using a counter variable. Its brackets contain three parts, separated by semicolons:

for (let i = 1; i <= 5; i++) {
    console.log(`Revision session ${i}`);
}
  1. let i = 1 runs once, before the loop starts, and creates the counter.
  2. i <= 5 is checked before every repeat. The loop keeps going while it is true, and stops as soon as it is false.
  3. i++ runs after every repeat, adding 1 to the counter.

This logs Revision session 1 through to Revision session 5. Each repeat is called an iteration. The counter is traditionally called i, short for index.

A for loop can go through an array by counting from 0 up to, but not including, its length:

for (let i = 0; i < topics.length; i++) {
    console.log(`${i + 1}. ${topics[i]}`);
}

This logs a numbered list. The number displayed is i + 1, because people count from 1, even though indexes start at 0.

The for...of Loop

When you need every item in an array but not its index, the for...of loop is simpler. It gives you each item in turn, with no counter to manage:

for (const topic of topics) {
    console.log(topic);
}

Read it as "for each topic of the topics array". Each time round the loop, topic holds the next item. By convention, the array's name is plural and the loop variable is the singular.

Building a String in a Loop

A common use of a loop is to build up a piece of text, adding to it on each iteration:

let list = "";

for (const topic of topics) {
    list += `• ${topic}\n`;
}

document.querySelector("#topic-list").textContent = list;

\n inside a string is a special code for a new line. The starter CSS has set the #topic-list element to keep new lines, so each topic appears on its own line.

The while Loop

A while loop repeats as long as its condition is true. It is useful when you do not know in advance how many times the loop will need to run:

let hoursLeft = 10;
let day = 1;

while (hoursLeft > 0) {
    console.log(`Day ${day}: ${hoursLeft} hours left`);
    hoursLeft -= 3;
    day++;
}
⚠️ Warning: If a loop's condition never becomes false, the loop never ends. This is called an infinite loop, and it freezes the page. In a while loop, make sure something inside the loop always moves it towards finishing, such as hoursLeft -= 3 above. In this platform, the preview stops any loop that runs for more than a second and shows a message, but on a real website, an infinite loop would freeze the user's browser tab.

Array Methods With Callbacks

Loops work, but they can be long-winded. Arrays also have methods that take a callback function and call it for every item, so you describe what to do with each item, and the method handles the looping. You met the first of these, forEach, in Lesson 5.

The examples below use this array of practice test results:

const scores = [72, 45, 58, 91, 63, 38];

forEach

forEach calls the function once for every item. It is the method version of for...of:

scores.forEach((score) => {
    console.log(`Score: ${score}`);
});

map

map creates a new array, by calling the function on every item and collecting what it returns. The new array always has the same number of items as the original:

const labels = scores.map((score) => `${score}%`);
console.log(labels);   // ["72%", "45%", "58%", "91%", "63%", "38%"]

filter

filter creates a new array containing only the items for which the function returns true:

const passes = scores.filter((score) => score >= 50);
console.log(passes);   // [72, 58, 91, 63]

find

find returns the first item for which the function returns true, or undefined if there is none:

const firstDistinction = scores.find((score) => score >= 70);
console.log(firstDistinction);   // 72

None of these methods change the original array. map and filter return new arrays, find returns a single item, and forEach returns nothing at all.

💡 Tip: Because map and filter return arrays, you can call another method straight after them, which is called chaining: scores.filter((score) => score >= 50).map((score) => `${score}%`) gives the passing scores as labels.
