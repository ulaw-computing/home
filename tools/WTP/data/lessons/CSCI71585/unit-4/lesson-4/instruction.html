Tutorial

As programs grow, the same tasks come up again and again: converting a value, formatting a price, updating part of the page. Rather than writing the same code each time, you can write it once as a function, give it a name, and run it whenever you need it. Functions are one of the most important ideas in programming, and almost everything you build from now on will use them.

What Is a Function?

A function is a named, reusable block of code that performs one task. You have already been using functions that are built into JavaScript: console.log(), Number() and Math.round() are all functions. The brackets after the name are what make them run.

Writing your own functions has several benefits:

  • Reuse: write the code once, and run it as many times as you like.
  • Easier changes: if the task changes, you only need to update it in one place.
  • Readability: a well-named function, such as calculateTotal(), tells the reader what the code does without them having to read every line of it.

Declaring and Calling a Function

A function is created with the function keyword, a name, a pair of brackets, and a block of code in curly braces:

function showWelcome() {
    document.querySelector("#greeting").textContent = "Welcome to your study tools!";
}

This is called declaring (or defining) a function. On its own, it does nothing: it only tells JavaScript what to do when the function is used. To run the code inside it, you call the function, by writing its name followed by brackets:

showWelcome();
💡 Tip: Name functions after what they do, starting with a verb: showWelcome, calculateTotal, convertToMiles. Like variables, function names use camelCase.

Parameters and Arguments

Most functions need some information to work with. A parameter is a variable listed in the function's brackets, which receives a value each time the function is called. The value you pass in when calling the function is called an argument:

function greetStudent(name) {          // name is a parameter
    console.log(`Hello, ${name}!`);
}

greetStudent("Amira");   // "Amira" is an argument: logs Hello, Amira!
greetStudent("Ben");     // logs Hello, Ben!

A function can have several parameters, separated by commas. The arguments are matched to the parameters in order:

function describeModule(code, title) {
    console.log(`${code}: ${title}`);
}

describeModule("CSCI71585", "Web Technologies");

Returning a Value

So far, your functions have done something, such as logging or changing the page. Many functions instead work something out and give the answer back. The return keyword sends a value back to wherever the function was called:

function convertToMiles(km) {
    return km * 0.621371;
}

const miles = convertToMiles(10);
console.log(miles);   // 6.21371

When convertToMiles(10) runs, the whole call is replaced by the value it returns, so miles becomes 6.21371. Because the function returns a value instead of displaying it, you can use the result however you like: display it, round it, or pass it to another function.

  • return stops the function immediately. Any code after it in the function does not run.
  • A function with no return gives back undefined.
💡 Tip: Functions that return a value, rather than changing the page themselves, are much easier to reuse. convertToMiles can be used anywhere, while a function that also writes to one particular element can only ever be used with that element.

Default Parameters

A parameter can have a default value, which is used if no argument is passed in for it:

function calculateStudyTime(sessions, minutesPerSession = 25) {
    return sessions * minutesPerSession;
}

console.log(calculateStudyTime(4));       // 100: uses the default of 25
console.log(calculateStudyTime(4, 50));   // 200

Parameters with defaults should come after the parameters without them, so that the arguments still line up in order.

Scope

A variable's scope is the part of the code where it can be used. Variables declared with let or const only exist inside the block, the curly braces, where they are declared:

const siteName = "Study Tools";   // declared outside: can be used anywhere

function showTotal() {
    const total = 100;             // declared inside: only exists in this function
    console.log(siteName);         // works
    console.log(total);            // works
}

// Out here, total does not exist.
  • A variable declared outside every function and block is in the global scope, and can be used anywhere in the script.
  • A variable declared inside a function, or any other block such as an if statement, can only be used inside it.

Scope is a good thing. It means each function can use simple variable names, such as total or result, without worrying that another part of the program is using the same name for something else.

💡 Tip: If a value needs to get out of a function, return it. If a value needs to get in, pass it as an argument. This keeps each function self-contained, and much easier to understand.

Arrow Functions

Arrow functions are a shorter way to write functions, using =>. They are usually stored in a const:

// A normal function declaration
function double(number) {
    return number * 2;
}

// The same function as an arrow function
const double = (number) => {
    return number * 2;
};

// Shorter still: with only one expression, the braces and return can be left out
const double = (number) => number * 2;

In the shortest form, the value after the arrow is returned automatically. With exactly one parameter, the brackets around it are optional too, so you may see number => number * 2.

Arrow functions are called in exactly the same way: double(5) returns 10. You will see them everywhere in modern JavaScript, especially in the next few lessons, where short functions are passed to other functions.

ℹ️ Info: The three versions of double above show the same function written three ways. In a real script, you could only declare the name double once.

Try It

  1. Replace your convertToFahrenheit function declaration with an arrow function in its shortest form, stored in a const with the same name. Delete the old version completely, since a name can only be declared once. Check that the temperature result is unchanged.
⚠️ Warning: A function declared with the function keyword can be called from anywhere in the script, even above the line where it is declared. An arrow function stored in a const cannot: it only exists from the line where it is declared onwards. Make sure the arrow function comes before the code that calls it, or your results will stop appearing.

Functions as Values

In JavaScript, a function is a value, just like a number or a string. This means a function can be passed into another function as an argument. A function passed in like this is called a callback, because the other function "calls it back" when the time is right.

A simple example is the built-in setTimeout function, which waits a number of milliseconds and then calls the function you give it:

function showReminder() {
    document.querySelector("#timer-message").textContent = "Time for a break!";
}

setTimeout(showReminder, 3000);   // calls showReminder after 3000 ms (3 seconds)
⚠️ Warning: Notice that there are no brackets after showReminder when it is passed to setTimeout. showReminder means "this function", while showReminder() means "run this function now". With brackets, the reminder would appear straight away, and setTimeout would be given the result instead of the function.

You can also pass an arrow function directly, without giving it a name first:

setTimeout(() => {
    console.log("Three seconds have passed.");
}, 3000);

Callbacks are the key to the rest of this unit. In Lesson 6, you will pass functions to run when the user clicks a button, and in Lesson 7, you will pass functions to run for every item in a list.
