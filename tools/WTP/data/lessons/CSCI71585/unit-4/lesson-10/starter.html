  • API: a way for one program to request data or services from another.
  • Browser: the program used to view websites, such as Chrome or Firefox.
  • CSS: the language used to style web pages.
  • DOM: the browser's model of a web page, which JavaScript can change.
  • Domain: the name of a website, such as example.com.
  • HTML: the language used to structure the content of web pages.
  • HTTP: the rules browsers and servers use to send pages to each other.
  • JavaScript: the programming language that makes web pages interactive.
  • JSON: a text format for sending data, based on JavaScript objects.
  • Server: a computer that stores websites and sends them to browsers.
  • URL: the address of a page or file on the web.
  • Viewport: the visible area of a web page in the browser window.
