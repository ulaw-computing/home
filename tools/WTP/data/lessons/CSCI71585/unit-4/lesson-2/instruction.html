What Is a Variable?

A variable is a named container for a value. Once a value is stored in a variable, you can use the name anywhere in your code to get the value back, and you can change the value later if you need to.

let studentName = "Amira";
console.log(studentName);   // Amira

This statement has three parts:

  • let is a keyword that creates (or declares) a new variable.
  • studentName is the variable's name.
  • = "Amira" assigns a value to it. In JavaScript, a single = always means "store this value", not "is equal to".

Notice that studentName has no quotes in console.log(studentName). Without quotes, JavaScript looks up the variable and uses its value. With quotes, console.log("studentName") would display the word studentName itself.


let and const

There are two keywords for declaring variables in modern JavaScript:

  • let declares a variable whose value can be changed later.
  • const (short for constant) declares a variable whose value cannot be replaced once it has been set.
let score = 10;
score = 15;            // allowed: score is now 15

const course = "MSc Computing";
// course = "MSc Law"; would not be allowed

When you change the value of a let variable, you do not write let again. let is only used once, when the variable is first created.

💡 Tip: Use const by default, and only use let when you know the value will need to change. This makes your code easier to understand, because anyone reading it knows that a const will always hold the same value.
ℹ️ Info: You will often see a third keyword, var, in older code and online examples. It was the only way to declare variables before 2015, and it behaves in some surprising ways that let and const were designed to fix. Recognise it, but do not use it in your own code.

Naming Variables

Variable names must follow a few rules:

  • They can contain letters, digits, underscores (_) and dollar signs ($), but no spaces or hyphens.
  • They cannot start with a digit.
  • They are case-sensitive: score and Score are two different variables.
  • They cannot be one of JavaScript's own keywords, such as let, const or if.

The standard convention in JavaScript is camelCase: the first word is lowercase, and each word after it starts with a capital letter, such as studentName or totalPrice. Choose names that describe what the value is: totalPrice is far clearer than tp or x.

⚠️ Warning: Notice the difference from CSS, where class names use hyphens, such as .total-price. In JavaScript, a hyphen means subtraction, so total-price would mean "total minus price". Use camelCase in JavaScript and hyphens in CSS.

Data Types

Every value in JavaScript has a type, which decides what you can do with it. The five you will use most are:

  • String: text, written in quotes, such as "Leeds". Single quotes, double quotes and backticks all create strings.
  • Number: any number, whole or decimal, such as 42 or 3.5. Numbers are written without quotes.
  • Boolean: either true or false, written without quotes. Booleans answer yes-or-no questions, such as whether a user is logged in.
  • Undefined: the value of a variable that has been declared but not given a value yet.
  • Null: a value that deliberately means "nothing" or "empty". You met this in Lesson 1, when querySelector could not find an element.

The typeof operator tells you the type of any value:

console.log(typeof "Leeds");   // string
console.log(typeof 42);        // number
console.log(typeof true);      // boolean

let nickname;
console.log(nickname);         // undefined
⚠️ Warning: "42" and 42 are different values. The first is a string, made of the characters 4 and 2, and the second is a number. As you will see later in this lesson, mixing them up causes some surprising results.

Working With Strings

Joining Strings

The + operator joins strings together. This is called concatenation:

const firstName = "Amira";
const greeting = "Hello, " + firstName + "!";
console.log(greeting);   // Hello, Amira!

Notice the space inside "Hello, ". JavaScript joins strings exactly as they are, so without it, the result would be Hello,Amira!.

Template Literals

Joining several strings and variables with + quickly becomes hard to read. A template literal is a string written in backticks (`) instead of quotes. Inside it, any value in ${ } is inserted into the string:

const firstName = "Amira";
const course = "MSc Computing";
const intro = `Hello, I am ${firstName} and I study ${course}.`;
console.log(intro);   // Hello, I am Amira and I study MSc Computing.
💡 Tip: The backtick key is usually at the top left of the keyboard, below Esc, on the same key as ¬ on a UK keyboard. A template literal must start and end with a backtick: a normal quote at either end will not work.

String Properties and Methods

Strings come with built-in tools. A property is a value that belongs to something, and a method is an action it can perform, which is always followed by brackets. Both are written after a dot:

  • .length is the number of characters in the string, including spaces.
  • .toUpperCase() and .toLowerCase() return a copy of the string in capitals or lowercase.
  • .trim() returns a copy with any spaces removed from the start and end, which is useful for tidying text a user has typed.
  • .includes("text") returns true if the string contains that text, and false if not.
const city = "Leeds";
console.log(city.length);            // 5
console.log(city.toUpperCase());     // LEEDS
console.log(city.includes("ee"));    // true
ℹ️ Info: String methods never change the original string. city.toUpperCase() gives you a new, uppercase copy, and city is still "Leeds". To keep the result, store it in a variable.

Working With Numbers

Arithmetic

  • + addition, - subtraction, * multiplication and / division.
  • ** raises to a power: 2 ** 3 is 8.
  • % gives the remainder after division: 10 % 3 is 1. This is useful for checking whether a number is even (number % 2 is 0).

JavaScript follows the same order of operations as maths, so multiplication and division happen before addition and subtraction. Use brackets to make the order clear: (2 + 3) * 4 is 20, while 2 + 3 * 4 is 14.

Updating a Value

Changing a number based on its current value is so common that there are shorter ways to write it:

let credits = 60;
credits = credits + 20;   // credits is now 80
credits += 20;            // the same thing, shorter: credits is now 100
credits++;                // add 1: credits is now 101
credits--;                // subtract 1: credits is now 100

These only work on let variables, since they replace the value.

Rounding

Decimals sometimes give long results, such as 10 / 3, which is 3.3333333333333335. Two common ways to tidy them are:

  • Math.round(number) rounds to the nearest whole number.
  • number.toFixed(2) rounds to 2 decimal places, which is ideal for prices. It returns a string, ready to display.
ℹ️ Info: Computers store decimals in binary, which cannot represent some decimal numbers exactly, in the same way that one third cannot be written exactly in decimal. This is why 0.1 + 0.2 gives 0.30000000000000004 in almost every programming language. Round results before displaying them.

Mixing Types

When an operator is given values of different types, JavaScript converts one of them automatically. This is called type coercion, and it is behind some of the most confusing results in JavaScript:

console.log("5" + 5);    // "55": + joins strings, so the 5 becomes text
console.log("5" * 2);    // 10:   * only works on numbers, so "5" becomes 5
console.log("5" - 2);    // 3

The + operator is the problem: it means addition for numbers, but concatenation for strings, and if either value is a string, it joins them.

To avoid surprises, convert values yourself before using them:

  • Number("5") converts a string to a number. If the string is not a number, such as Number("hello"), the result is NaN, meaning Not a Number.
  • String(5) converts a number to a string.
⚠️ Warning: Everything a user types into a web page, whether in a text box or any other form field, reaches JavaScript as a string, even if it looks like a number. If you add "20" typed by a user to the number 10, you get "2010", not 30. Always convert user input with Number() before doing maths with it. You will see this in practice in Lesson 6.
