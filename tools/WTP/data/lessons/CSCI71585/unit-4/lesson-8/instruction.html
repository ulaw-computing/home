Tutorial

An array is ideal for a list of similar things, but many things in the real world have several different pieces of information that belong together. A workshop session has a title, a time, a level and a speaker. A product has a name, a price and a description. In this lesson you will learn how JavaScript groups related values into a single object, and how to work with arrays of objects, which is how almost all real data is organised, including the data you will fetch from the web in the next unit.

The starter code contains a schedule page for the Beginners' Web Workshop. As before, keep the console open, and complete each Try It section in the editor before moving on.


Why Objects?

Imagine storing the details of one workshop session in separate variables:

const sessionTitle = "Your First HTML Page";
const sessionTime = "10:30";
const sessionLevel = "beginner";

This works for one session, but the variables are only connected by their names. With ten sessions, you would need thirty variables, and no easy way to keep each session's details together. An object solves this.


Creating an Object

An object is a collection of properties. Each property has a name (also called a key) and a value. An object is written in curly braces, with each property as name: value, separated by commas:

const session = {
    title: "Your First HTML Page",
    time: "10:30",
    level: "beginner",
    durationMinutes: 90,
    isFull: false
};
  • Property names follow the same rules as variable names, and use camelCase.
  • Values can be of any type: strings, numbers, booleans, arrays and even other objects.
  • Each property ends with a comma, except the last one. A comma after the last property is allowed, but not needed.
⚠️ Warning: Do not confuse the curly braces of an object with the curly braces of a block, such as in an if statement or function. Inside an object, properties are separated by commas, not semicolons, and each one uses a colon, not an equals sign.

Reading and Changing Properties

Dot Notation

The usual way to get a property is dot notation: the object's name, a full stop, and the property's name:

console.log(session.title);   // "Your First HTML Page"
console.log(session.time);    // "10:30"

You have been using dot notation since Lesson 1. console.log is the log property of the built-in console object, and topics.length is the length property of an array.

You can change a property, or add a new one, by assigning to it:

session.isFull = true;          // changes an existing property
session.room = "2.04";          // adds a new property

As with arrays, an object declared with const can still have its properties changed.

If you read a property that does not exist, the result is undefined. This often means the property name has been misspelt: session.tittle gives undefined, with no other warning.

Bracket Notation

Properties can also be read with bracket notation, with the property name as a string:

console.log(session["title"]);   // the same as session.title

Bracket notation is needed when the property name is stored in a variable, since dot notation would look for a property called, literally, the variable's name:

const detail = "level";
console.log(session[detail]);   // "beginner"
console.log(session.detail);    // undefined: there is no property called "detail"

Objects Inside Objects

A property's value can be an array, or another object. This lets you represent more complex information:

const session = {
    title: "Your First HTML Page",
    speaker: {
        name: "Amara Kofi",
        role: "Lead Developer"
    },
    topics: ["Elements", "Headings", "Links"]
};

console.log(session.speaker.name);   // "Amara Kofi"
console.log(session.topics[0]);      // "Elements"
console.log(session.topics.length);  // 3

Read session.speaker.name from left to right: in session, get speaker, and in that, get name.

Methods

A property's value can also be a function. A function stored in an object is called a method, and it describes something the object can do. Inside a method, the keyword this refers to the object the method belongs to:

const session = {
    title: "Your First HTML Page",
    time: "10:30",
    describe() {
        return `${this.title} starts at ${this.time}.`;
    }
};

console.log(session.describe());   // "Your First HTML Page starts at 10:30."

You have used many built-in methods already: toUpperCase() is a method of strings, push() is a method of arrays, and querySelector() is a method of the document object.

ℹ️ Info: this behaves differently inside arrow functions, so write methods using the short form above, describe() { ... }, rather than as arrow functions.

Arrays of Objects

The real power of objects comes when you put several of them in an array. Each object describes one item, and the array holds the whole collection:

const sessions = [
    { id: 1, title: "How the Web Works", time: "10:00", level: "beginner" },
    { id: 2, title: "Your First HTML Page", time: "10:30", level: "beginner" },
    { id: 3, title: "Styling With CSS", time: "13:30", level: "intermediate" }
];

Short objects can be written on one line, like these. To get a value, first choose the object by its index, then the property with dot notation: sessions[1].title is "Your First HTML Page".

Everything you learned about arrays in the last lesson works with arrays of objects. In each callback, the parameter is a whole object, so you use dot notation on it:

// Loop through every session
for (const session of sessions) {
    console.log(`${session.time} ${session.title}`);
}

// Only the beginner sessions
const beginnerSessions = sessions.filter((session) => session.level === "beginner");

// Just the titles
const titles = sessions.map((session) => session.title);

// The session with a particular id
const chosen = sessions.find((session) => session.id === 3);
💡 Tip: Giving each object a unique id property, as above, is a very common pattern. It gives you a reliable way to find one particular item, even if two items have the same title.

Objects and JSON

In the next unit, you will fetch data from APIs: services on the web that send data to your page. Almost all of them send it in a format called JSON (JavaScript Object Notation), which is based on exactly the objects and arrays you have learned in this lesson:

[
    { "id": 1, "title": "How the Web Works", "time": "10:00", "level": "beginner" },
    { "id": 2, "title": "Your First HTML Page", "time": "10:30", "level": "beginner" }
]

JSON looks almost identical to a JavaScript array of objects. The main differences are that property names must be in double quotes, strings must use double quotes, and JSON cannot contain functions. Once JSON data has been loaded into your page, it becomes ordinary JavaScript arrays and objects, and you work with it using exactly the loops and methods you have used today.


Check Your Page

Your session list code should be similar to this:

let list = "";

for (const session of sessions) {
    list += `${session.time} – ${session.title} (${session.level})\n`;
}

document.querySelector("#session-list").textContent = list;

const beginnerSessions = sessions.filter((session) => session.level === "beginner");
document.querySelector("#beginner-count").textContent =
    `${beginnerSessions.length} sessions are suitable for beginners.`;

const featured = sessions.find((session) => session.id === 4);
document.querySelector("#featured-session").textContent =
    `${featured.title} with ${featured.speaker.name}`;

Also check that the single session at the top of the page shows its title, details, speaker and topics.
